# 🚀 GetSynced

An AI-powered productivity workspace built with **React, TypeScript, FastAPI, PostgreSQL, SQLAlchemy, and OpenAI**.

---

## 📖 Overview

GetSynced is a full-stack AI productivity application that combines task management, note-taking, calendar scheduling, and an intelligent AI assistant into one unified workspace.

Instead of switching between multiple apps, users can manage their productivity and interact with their workspace using natural language.

---

## ✨ Features

- 🤖 AI Assistant
- ✅ Task Management
- 📝 Notes
- 📅 Calendar Events
- ✨ Plan My Day
- 📊 Prioritize Tasks

- 💾 Persistent PostgreSQL Database

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/ameenp2005/GetSynced.git
```

### Backend

```bash
cd backend
python -m venv venv
pip install -r requirements.txt
```

Create a `.env` file with your required environment variables.

Start the backend:

```bash
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend2
npm install
npm run dev
```
